# БИОМ

Лендинг домашней станции БИОМ, которая видит споры плесени под микроскопом 40x и сама включает осушитель.

Сайт целиком в одном файле `index.html`: стили, скрипты и картинки встроены внутрь.

## Как опубликовать на GitHub Pages

1. Загрузите `index.html`, `.nojekyll` и `README.md` в корень публичного репозитория.
2. Откройте Settings → Pages → Build and deployment → Deploy from a branch, выберите ветку `main` и папку `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Фото станции — визуализации концепта, не серийный образец.
